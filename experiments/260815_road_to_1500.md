# Road to 1500

## Target

Current best 2024 screening result is roughly Brier 0.24792 / score 756. Reaching a competition-style score near 1500 requires a much larger Brier improvement than the game_type correction alone can provide.

The strategy therefore separates small calibration gains from new predictive signal.

## Assumption

Treat evaluation pitchers as unseen identities.

- Do not depend on pitcher_id memorization.
- Do not depend on pitcher_id -> Trackman lookup at inference.
- Trackman may be used as training-time privileged information only if it can teach a relation that transfers to unseen pitchers through official inference-time variables.

## Phase 1 — Lock the hard validation

Run both ordinary temporal validation and an all-pitchers-unseen stress test.

```powershell
python scripts/run_unseen_pitcher_validation.py --config configs/default.yaml
```

The strict protocol removes every pitcher appearing in 2024 from all 2019-2023 training rows, then evaluates on the full 2024 fold.

This is intentionally pessimistic. It answers whether a proposed feature/model survives without pitcher identity reuse.

## Phase 2 — Audit Trackman before modeling

```powershell
python scripts/analyze_trackman_for_unseen_pitchers.py --config configs/default.yaml
```

If the file is elsewhere:

```powershell
python scripts/analyze_trackman_for_unseen_pitchers.py --config configs/default.yaml --trackman <path-to-trackman_history.csv>
```

The audit reports identity overlap, temporal columns, physical variables, season coverage, missingness, and per-pitcher support.

Do not build a Trackman model until temporal alignment and identity mapping are confirmed.

## Phase 3 — Find signal, not calibration

Priority feature families once Trackman alignment is confirmed:

1. release stability and dispersion;
2. recent-vs-long-run velocity/release/movement shifts;
3. pitch repertoire / pitch-mix state;
4. workload / appearance recency if a safe time axis exists;
5. population-level relations between official as-of statistics and Trackman physical state.

Every family must be evaluated against both ordinary 2024 temporal validation and the unseen-pitcher stress test.

## Phase 4 — Privileged-information teacher

If Trackman strongly improves a teacher but cannot exist at inference:

```text
teacher: official features + leakage-safe historical Trackman state
student: official inference-time features only
```

Test whether distillation recovers part of the teacher gain for unseen pitchers. If the teacher itself does not materially beat the raw model, stop Trackman work early.

## Phase 5 — Final stacking/calibration

Only after a stronger base predictor is found:

- F correction/hybrid from the completed game_type experiments;
- strict forward probability calibration;
- conservative model blending.

These are finishing layers, not the primary path from ~750 to 1500.

## Promotion rule

A new idea is promoted only if it satisfies at least one of the following without a large regression on the other validation protocol:

- meaningful 2024 Brier reduction on ordinary temporal validation;
- meaningful improvement under all-pitchers-unseen stress;
- substantial teacher gain that can plausibly be distilled.

Do not optimize dozens of tiny hyperparameters on 2024. Prefer new information, robust feature families, and fixed forward-safe rules.
