## Provenance and intended use

The SAFE training semantics were recovered from the Git object snapshot and historical constituent scripts referenced in `configs/baseline_safe_981.yaml`. The public Bitaboost interface remains config-driven and the recovered historical implementation is quarantined under `src/bitaboost/_legacy/`.

This checkpoint is the research baseline to return to before future ablations. Do not reinterpret the current score as a new holdout result: 2024 has already been used extensively for validation and model selection.

The dated checkpoint branch should be treated as immutable. The `bitaboost-stable` branch is the promoted stable line; future experiments should branch from `bitaboost` or `experiments/` and only be promoted after explicit validation.
